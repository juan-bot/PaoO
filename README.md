# PaoO

Página web de regalos personalizados: cartas, flores y detalles interactivos.

## Contenido

- `Calma/` — Página de relajación
- `Carta/`, `Cumpleanos/`, `DiaMaestro/` — Cartas y felicitaciones temáticas
- `flores/` — Animación de flores

## Stack

- HTML, CSS y JavaScript

## Uso

Abrir `index.html` en el navegador.
